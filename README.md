# FF Manager

Basic fantasy football companion dashboard.

## Features (v0.1)
- Clean modern UI with light / dark mode
- League summary card (mock data)
- External link to RedZone audio (credited)
- Mobile-friendly

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repo
2. Import the repo on [vercel.com](https://vercel.com)
3. Deploy (Next.js is auto-detected)

Theme preference is saved in localStorage.
